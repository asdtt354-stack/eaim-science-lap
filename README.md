# 🔬 EAIM 과학 놀이터 (eaim-science-lap)

> 감정과 이야기로 배우는 중학교 과학 — Emotion · Artscape · Interactive · Musicalization

🔗 배포 주소: https://eaim-science-lap.vercel.app

과정형 저장소입니다. 교과서 단원 흐름을 따라가는 **소단원 페이지**, 스스로 점검하는 **셀프체크룸**, 그리고 AI와 함께하는 **체험 앱**으로 이루어져 있습니다.

## 🧩 공통 파일

| 파일 | 설명 |
|---|---|
| `api/ai.js` | AI 중계 서버 함수. 음악과 `eaim-play` 저장소의 기준본을 그대로 복사한 것이므로 **이 저장소에서 고치지 않습니다.** 설정 방법은 파일 맨 위 주석을 봅니다. |
| `package.json` | `api/ai.js`가 동작하는 데 필요합니다. 지우지 마세요. |
| `lib/qrcode.min.js` | QR 코드를 화면에서 직접 그리는 라이브러리(MIT). 외부 QR 서비스를 쓰지 않습니다. |
| `muto.png` | 뮤토 기분 확인 그림 |
| `self-check-room/shared/` | 셀프체크룸 기록(`tracker.js`)과 교사 대시보드 연동(`teacher-tracker.js`) |

## 👩‍🏫 사용 방법

**교사**: AI 체험 앱을 열어 구글 계정으로 로그인 → 반/모둠 만들기 → 수업 켜기 → 반별 QR·링크를 학생에게 공유. 생활 과학 공감 톡은 "오늘의 단원"도 정해 둡니다.

**누구나 (공개)**: 태양계·천문대·지구·인체 탐험대는 링크 없이 열어도 로그인 없이 바로 관찰할 수 있습니다. AI 미션과 기록만 수업 링크로 들어왔을 때 열립니다. 선생님은 화면 왼쪽 아래 "👩‍🏫 선생님" 버튼으로 로그인합니다. 생활 과학 공감 톡은 활동 전체가 AI라 수업 링크로만 씁니다.

**학생 (수업)**: 선생님이 준 QR·링크로 들어와 **반과 번호**를 적습니다. 로그인은 필요 없고, 이름은 적지 않아도 되며 적으면 첫 글자만 보입니다. 셀프체크룸도 처음에 반과 번호를 한 번 적습니다.

**AI 키**: 키는 학생 기기로 내려가지 않고 서버(중계 함수)에서만 쓰입니다. 교사 본인 키를 넣을 때는 키에 **API 제한(Generative Language API)과 하루 한도만** 걸고, 웹사이트 제한은 걸지 않습니다.
